# Averium
## Information
Averium is Minecraft mod specifically for version 1.20.1. It utilises Forge 47.4.0 and above. Averium is currently still in early development.

## Description
Averium is a small content mod, adding in magical and unstable metals into Minecraft. Each of the metals is endgame-focused and have their own unique properties to deal with. Some are more annoying than others.

Features include:
- Badly sprited blocks and items.
- Curios! Yay!
- Why am I on fire in the Nether? (You tell me)
- Items in your inventory hate you.

## Dependencies (Specific Versions)
- Forge v47.4.0 (Until I learn Fabric or something)
- Curios API v5.14.1+1.20.1
- Just Enough Items v15.20.0.106 (Optional)

Unfortunately, these specific versions will stay until I increase my IQ and learn how to accommodate for other versions.
